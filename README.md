# 📊 React Dashboard App

Dashboard interactivo desarrollado con React para la visualización de datos mediante gráficas dinámicas y consumo de APIs. Este proyecto forma parte de mi portafolio como Frontend Developer y demuestra la construcción de interfaces modernas, escalables y orientadas a datos.

## 🧠 Descripción

Este dashboard permite representar información clave a través de diferentes tipos de gráficos, proporcionando una experiencia visual clara e interactiva. Está construido siguiendo buenas prácticas de desarrollo frontend, con enfoque en escalabilidad y mantenibilidad.

El proyecto simula un entorno real de análisis de datos, ideal para aplicaciones empresariales, sistemas de monitoreo o herramientas analíticas.

## ⚙️ Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/CodeKiller99/react-dashboard.git
```

2. Acceder al proyecto:

```bash
cd react-dashboard
```

3. Instalar dependencias:

```bash
npm install
```

4. Ejecutar en entorno de desarrollo:

```bash
npm run dev
```

---

## 🌐 Variables de entorno

Si el proyecto consume una API externa, puedes configurar:

```
VITE_API_URL=your_api_url_here
```
